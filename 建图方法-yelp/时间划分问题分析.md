# 时间划分问题深度分析

## 1. 问题概述

当前系统中存在**两处独立的时间划分**，它们的目的不同，但可能导致**数据泄露**和**逻辑混乱**。

---

## 2. 两处时间划分的对比

### 2.1 建图阶段的划分（新建图方法/main.py）

**位置**：`新建图方法/main.py` → `create_data_splits()`

**目的**：将节点划分为训练集/验证集/测试集

**方式**：按时间顺序，前60%为训练集，中间20%为验证集，后20%为测试集

```python
train_end = int(n * 0.6)
val_end = int(n * 0.8)

train_mask[:train_end] = True      # 节点 0 ~ 60%
val_mask[train_end:val_end] = True # 节点 60% ~ 80%
test_mask[val_end:] = True         # 节点 80% ~ 100%
```

**划分对象**：**节点**（评论）

**输出**：`splits.pkl` 包含 `train_mask`, `val_mask`, `test_mask`


### 2.2 模型阶段的划分（异构图欺诈检测模型/src/utils/temporal_split.py）

**位置**：`异构图欺诈检测模型/src/utils/temporal_split.py` → `TemporalGraphSplitter`

**目的**：将完整图按时间划分为多个快照（Snapshot），供DySAT时序注意力使用

**方式**：均匀分割时间轴为 N 个时间片（默认8-15个）

```python
boundaries = np.linspace(t_min, t_max, num_snapshots + 1)

for i in range(num_snapshots):
    t_start, t_end = boundaries[i], boundaries[i + 1]
    node_mask = (timestamps >= t_start) & (timestamps < t_end)
    # 创建该时间片的子图...
```

**划分对象**：**图快照**（包含节点和边）

**输出**：`List[Data]` 时间片快照列表

## 3. 当前存在的问题

### 3.1 问题一：两种划分相互独立，没有协调

| 划分 | 时间范围 | 划分对象 | 是否考虑另一个划分 |
|------|----------|----------|-------------------|
| 建图阶段 | 全部数据 | 节点 | ❌ 不考虑时间片 |
| 模型阶段 | 全部数据 | 图快照 | ❌ 不考虑train/val/test |

**结果**：模型阶段的时间片划分是在**全部数据**上进行的，包括训练集、验证集和测试集的节点。

### 3.2 问题二：数据泄露风险

在模型训练时：

```
时间片 1: [节点0-5000]     ← 全是训练集节点
时间片 2: [节点5000-10000] ← 全是训练集节点
...
时间片 6: [节点20000-25000] ← 包含训练集+验证集节点 ⚠️
时间片 7: [节点25000-30000] ← 包含验证集+测试集节点 ⚠️
时间片 8: [节点30000-39000] ← 全是测试集节点 ⚠️
```

**问题**：
1. 训练时，HGT消息传递可能通过边连接到验证/测试集节点
2. 时序注意力聚合时，训练集节点可能"看到"未来时间片的信息
3. TGN记忆模块可能存储了未来节点的信息

### 3.3 问题三：边的时间过滤缺失

在 `temporal_split.py` 的 `_create_snapshot()` 中：

```python
# 选择边：源节点和目标节点都在时间窗口内
edge_mask = node_mask[edge_index[0]] & node_mask[edge_index[1]]
```

**问题**：只检查了边的两端节点是否在时间窗口内，**没有检查边的时间戳**。

这意味着：
- 如果边 (i, j) 的两端节点都在时间片 T 内
- 但边的事件时间 `t_raw(e) = max(t_raw(i), t_raw(j))` 可能在时间片 T 之后
- 这条边仍然会被包含在时间片 T 中 ⚠️

## 4. 数据流分析

### 4.1 当前数据流

```
┌─────────────────────────────────────────────────────────────────┐
│                        建图阶段                                  │
│  新建图方法/main.py                                              │
│                                                                  │
│  1. 构建完整图（全部节点、全部边）                                │
│  2. 节点划分：train/val/test mask（按时间顺序60/20/20）          │
│  3. 输出：graph.pkl, splits.pkl                                  │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        模型阶段                                  │
│  异构图欺诈检测模型/                                             │
│                                                                  │
│  1. data_loader.py: 加载完整图 + splits                          │
│  2. temporal_split.py: 在【全部数据】上划分时间片                │
│     ⚠️ 没有考虑 train/val/test 边界                              │
│  3. ht_gat_fraud.py: 对每个时间片进行HGT处理                     │
│     ⚠️ 训练时可能通过边"看到"验证/测试集节点                     │
│  4. 时序注意力聚合所有时间片                                     │
│     ⚠️ 可能聚合了未来时间片的信息                                │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 问题示意图

假设有39000个节点，按时间排序：

```
时间轴: ──────────────────────────────────────────────────────────→

节点:   [0────────────23400]  [23400────31200]  [31200────39000]
              训练集              验证集              测试集
              (60%)              (20%)              (20%)

时间片: [片1][片2][片3][片4][片5][片6][片7][片8]
        ←─────────────────────────────────────────→
                    全部数据上划分

问题：
- 时间片6可能同时包含训练集和验证集节点
- 时间片7可能同时包含验证集和测试集节点
- 训练时，HGT消息传递可能跨越train/val/test边界
```

## 5. 边时间戳未被使用的问题

### 5.1 建图阶段已保存边时间戳

在 `graph_builder.py` 中，我们已经为每条边计算并保存了：
- `timestamp`：边事件时间（秒），`max(t_raw(i), t_raw(j))`
- `timestamp_norm`：归一化边时间戳 [0, 100]
- `time_diff`：时间差（天）

### 5.2 模型阶段未使用边时间戳

在 `data_loader.py` 中，只提取了：

```python
# 只提取了边索引和边类型
edge_index = np.array(all_edges, dtype=np.int64).T
edge_type = np.array(all_edge_types, dtype=np.int64)
```

**没有提取**：
- `edge_timestamps`：边时间戳数组
- `edge_attributes` 中的 `weight`：边权重

### 5.3 时间片划分未使用边时间戳

在 `temporal_split.py` 中：

```python
# 只根据节点时间戳选择边
edge_mask = node_mask[edge_index[0]] & node_mask[edge_index[1]]
```

**应该改为**：

```python
# 根据边时间戳选择边
edge_mask = (edge_timestamps >= t_start) & (edge_timestamps < t_end)
```

## 6. 解决方案

### 6.1 方案一：严格时序划分（推荐）

**原则**：训练时只能看到"过去"的信息

**实现**：
1. 在建图阶段，根据 train/val/test 边界过滤边
2. 训练集只包含两端节点都在训练集内的边
3. 验证时，可以使用训练集+验证集的边
4. 测试时，可以使用全部边

```python
# 训练时的边过滤
train_edge_mask = train_mask[edge_index[0]] & train_mask[edge_index[1]]

# 验证时的边过滤
val_edge_mask = (train_mask | val_mask)[edge_index[0]] & \
                (train_mask | val_mask)[edge_index[1]]
```

### 6.2 方案二：基于边时间戳的时间片划分

**原则**：时间片内的边必须在该时间片的时间范围内

**实现**：

```python
def _create_snapshot(self, data, t_start, t_end):
    # 1. 选择时间窗口内的节点
    node_mask = (node_timestamps >= t_start) & (node_timestamps < t_end)
    
    # 2. 选择时间窗口内的边（基于边时间戳）
    edge_mask = (edge_timestamps >= t_start) & (edge_timestamps < t_end)
    
    # 3. 进一步过滤：边的两端节点必须都已存在
    edge_mask = edge_mask & (node_timestamps[edge_index[0]] < t_end) & \
                            (node_timestamps[edge_index[1]] < t_end)
```

### 6.3 方案三：归纳式学习（Inductive Learning）

**原则**：测试集节点在训练时完全不可见

**实现**：
1. 训练时，完全移除验证/测试集节点及其相关边
2. 验证时，将验证集节点作为"新节点"加入
3. 测试时，将测试集节点作为"新节点"加入

## 8. 总结

### 8.1 当前问题

1. **两处独立的时间划分**：建图阶段划分节点，模型阶段划分时间片，两者没有协调
2. **数据泄露风险**：训练时可能通过边或时序注意力"看到"未来信息
3. **边时间戳未使用**：已计算但未在模型中使用
4. **边权重未使用**：时间衰减权重、极端性权重等未被利用

### 8.2 建议优先级

1. **高优先级**：修复数据泄露问题（方案一或方案二）
2. **中优先级**：在模型中使用边时间戳
3. **低优先级**：在模型中使用边权重

### 8.3 是否需要重新建图？

**不需要**。当前建图阶段已经保存了所有必要的时间信息：
- 节点时间戳：`timestamps`
- 边时间戳：`edge_timestamps`（新增）
- 边属性：`timestamp`, `timestamp_norm`, `time_diff`

只需要修改**模型阶段**的代码，正确使用这些时间信息即可。
